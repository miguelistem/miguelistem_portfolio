Dual-cell production
line balancer

I designed and programmed a dual-cell production line balancer using CODESYS (Ladder Logic) and Factory I/O to synchronize two CNC lines producing matching bases and lids. I created autonomous conveyor feed logic using CNC status signals and entrance/exit sensors with Set/Reset latches to track part presence in each machine. To prevent line imbalance, I used counter blocks on the exit sensors to track output totals and comparison blocks to evaluate count differentials. If one line ran ahead or stalled, a hold variable was AND-gated with part-presence logic to hold the machine cycle trigger until counts rebalanced.

Plant Floor Layout & Tooling

01 // TRACKING

Set/Reset latches &
part-presence state

Fleeting optical sensor pulses can easily cause race conditions in cyclical scan execution. Entrance and exit retroreflective photo-eyes feed Set/Reset (SR) latches in ladder logic to maintain unambiguous part-presence memory inside each CNC chamber, interlocking machine doors and clamping sequences safely.

02 // ACCOUNTING

Exit counter blocks &
differential CMP

IEC 61131-3 CTU (Count-Up) function blocks placed on outfeed exit sensors continuously track cumulative base and lid completions. CMP (Comparison) blocks calculate the real-time differential between both lines to detect production imbalance the moment cycle times drift.

03 // INTERLOCK

AND-gated hold
machine cycle trigger

When count differentials exceed the safety margin, a HOLD variable asserts in the PLC memory. This variable is wired in series (AND gate) with part-presence logic on the machine cycle trigger rung. The lead CNC line pauses immediately while the lagging line continues uninterrupted until output is equalized.

System invariants

Engineering rules

Invariant 01

Deterministic Scan Execution

All ladder logic rungs execute strictly within deterministic PLC scan cycles. Latched state machines prevent asynchronous race conditions between conveyor motors, pneumatic stops, and CNC spindle commands.

Invariant 02

Zero Downstream Starve or Jam

Matching base and lid pairs are required in a 1:1 ratio for final assembly. Autonomous balancing ensures infeed queues never buffer to overflow, eliminating conveyor logjams and avoiding expensive downstream idle time.

Invariant 03

Fail-Safe Permissive Handshakes

Machine cycles cannot trigger without active confirmation of door closure, part clamp engagement, and absence of a hold interlock. Any sensor disconnect or emergency stop drops the run permissive immediately.

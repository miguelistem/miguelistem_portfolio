Plant operations, automated

A continuous operations layer for a 24/7 plastic-film manufacturing facility. One centralized database, four distinct kinds of trigger: a shift briefing that runs on a cron schedule, a material depletion forecast, a calendar change-detection sync, and an approval chain that pauses on humans before committing state changes.

Core Automation Principle: A valid schedule move still never applies itself autonomously. It halts at a wait-for-approval human gate; only when the operations manager signs off does the event sync across Outlook calendars and database line ledgers.

Three agents, one real inbox

A production orchestrator running on a local 7B parameter open-weights model that classifies every incoming operational email and hands it to a dedicated specialist: one drafts polite replies behind a human Discord approval gate, and one extracts job tracker parameters into Excel. Nothing ever sends itself without human sign-off.

Privacy & Safety Rule: Operates completely on local hardware via LM Studio. Proprietary client communications never touch third-party cloud LLM APIs, and sensitive outbound drafts are held in an approval queue until verified.

The engine finds it. The model explains it.

Stockfish scores every move in a player's history with ruthless mathematical precision; a local language model turns the pattern of blunders into coaching written in human chess terminology rather than raw centipawn delta numbers.

Translation Layer: Bridging the gap between brute-force search engines and human learning. Rather than staring at "-3.4 on move 14", players receive plain-English diagnosis of weak squares, pin vulnerabilities, and tactical oversights.

Swarm Agents8 to 12 Autonomous UAVs

Local AvoidanceReciprocal Velocity Obstacles (RVO)
Referee ArchitectureIndependent Collision Auditor
Policy TrainingMulti-Agent PPO (Centralized Critic)
Simulation PlatformNVIDIA Isaac Sim + 2D Engine

Eight drones, one corridor

Global A* gives each drone a waypoint path through narrow openings; local reciprocal velocity obstacle avoidance keeps them from colliding in the doorway. An independent collision checker audits every single frame and never steers — acting as a strict referee rather than a forgiving controller.

Referee Separation: The collision auditor has zero authority to correct trajectories. If two drones brush, it flags a true safety failure. This ensures the MAPPO policy genuinely learns cooperative deconfliction without hidden crutches.

FPGA Datapath Telemetry

Target SiliconXilinx Artix-7 (Basys 3 / Vivado)

Number FormatQ16.16 Fixed Point (Zero Float Latency)
Throughput Rate1 Agent Pair Retired / Clock Cycle
Host Interface115,200 Baud UART Serial Bus
Output BitmapSingle-Bit Collision Truth Vector

Collision checking, pushed to hardware

The mathematical bottleneck of multi-agent swarm planning is O(N²) pair-wise distance checks. This project offloads that quadratic math from the host CPU into custom silicon: a five-stage fixed-point datapath retiring one agent pair per clock cycle, benchmarked directly against the CPU reference.

Hardware Efficiency: Using Q16.16 fixed-point arithmetic eliminates the high area and latency penalty of floating-point units on FPGAs, delivering deterministic microsecond collision auditing for high-density autonomous fleets.
